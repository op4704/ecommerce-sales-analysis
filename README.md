# E-Commerce Sales Analysis & Prediction

End-to-end pipeline for analyzing e-commerce transaction data and forecasting
future sales revenue: load, clean, explore, engineer features, train models,
evaluate, and predict.

## Dataset

Online Retail II (UCI Machine Learning Repository / Dr. Daqing Chen, LSBU).
Real transaction data from a UK-based online retailer, Dec 2009 - Dec 2011,
~1M rows.

Source: https://archive.ics.uci.edu/dataset/502/online+retail+ii

## Project structure

```
data/
  raw/            # original dataset (gitignored, pulled at runtime)
  processed/      # cleaned/feature data (gitignored, generated by notebooks)
notebooks/        # 01 -> 07, load through prediction
src/ecommerce_sales_analysis/   # pipeline logic as reusable modules
reports/          # forecast output, final write-up
```

## Setup

```bash
uv sync
uv run pytest -v
uv run python -m ecommerce_sales_analysis.data_loader   # pulls the dataset
uv run jupyter lab
```

Work through the notebooks in order — each stage builds on the output of the
last (raw data -> cleaned -> daily features -> trained model -> forecast).

## Results

Random Forest was the best-performing model, ~34% RMSE improvement over a
naive "predict yesterday's revenue" baseline. 14-day forecast and full
write-up are in `notebooks/07_prediction_report.ipynb`.

Some findings from EDA:
- UK is ~83% of total revenue — market concentration risk.
- Top 20% of customers drive ~77% of revenue.
- Revenue per line item has a long right tail from bulk/wholesale orders.

See `notebooks/03_eda_visualization.ipynb` for the charts.
